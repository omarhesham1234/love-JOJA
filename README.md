# JOJO SENIOR 2026 — CINEMATIC EDITION

نسخة مطورة ببوابة تخرج بستائر بورجندي وذهب وحركة فتح سينمائية ناعمة وموسيقى خلفية أصلية مولدة خصيصًا للمشروع.

## التشغيل

```bash
npm install
npm run dev
```

## ملاحظة الموسيقى
المشروع يحتوي على موسيقى ambient أصلية قصيرة داخل `src/assets` حتى لا يحتاج الموقع لحقوق أغنية تجارية، مع زر تشغيل/إيقاف ثابت.
إذا أردت أغنية معينة لاحقًا، ضع ملفًا مرخصًا/تملكه داخل `src/assets` وغيّر مسار `music` في `src/main.jsx`.
